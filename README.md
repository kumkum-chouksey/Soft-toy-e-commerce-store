# 🧸 Cozy Bug – Cute & Cozy E-Commerce Website UI

**A Hug in Every Little Package. 💜**

Cozy Bug is a responsive, multi-page e-commerce website designed for a cute and cozy shopping experience. The website showcases a collection of adorable soft toys, plush accessories, teddy tote bags, cute pouches, notebook covers, keychains and other aesthetic products.

The project focuses on creating an attractive user interface, easy navigation and a smooth browsing experience across desktop, tablet and mobile devices.

## ✨ Features

### 1. Home Page
- Attractive hero section with brand introduction and an Explore Now button.
- Featured and best-selling product sections.
- Promotional offer section highlighting selected products.
- Customer testimonials section.
- Responsive navigation bar and footer.

### 2. Product Page
- Dedicated page to showcase the product collection.
- Product images with names and pricing.
- Organized product cards for easy browsing.
- Clean and user-friendly product layout.

### 3. Product Details / Offer Details Page
- Dedicated product information section.
- Large product image with smaller thumbnail images.
- Interactive image gallery using HTML and CSS.
- Product name, price, rating and description.
- Quantity selection.
- Add to Cart and Buy Now interface.

### 4. Login Page
- Dedicated login interface.
- User-friendly form layout.
- Responsive design for different screen sizes.

### 5. Responsive Design
- Responsive layouts for desktop, tablets and mobile devices.
- Hamburger navigation menu for smaller screens.
- Flexible product grids and image galleries.
- Responsive footer and content sections.
- Media queries to adapt layouts to different screen sizes.

## 🛠️ Technologies Used
HTML5 : Website structure and content 
CSS3 : Styling, layouts, animations and responsiveness 
JavaScript : Hamburger menu interaction 
Font Awesome : Icons and visual elements

## 📱 Responsive Design

The website is designed to work across different screen sizes:

- **Desktop:** Multi-column layouts and full navigation menu.
- **Tablet:** Adjusted grids, spacing and navigation.
- **Mobile:** Stacked layouts, compact product images and hamburger navigation.

CSS media queries are used to maintain usability and visual consistency across devices.

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:
   git clone (https://github.com/kumkum-chouksey/Soft-toy-e-commerce-store.git)

2. Open the project folder:
   cd soft-toy-e-commerce-store

3. Open index.html in your browser.

You can also open the project using Visual Studio Code and the Live Server extension.

## 🎯 Project Objective

The objective of Cozy Bug is to develop a visually appealing and responsive e-commerce website while strengthening practical frontend development skills.

This project provides hands-on experience with:
- Structuring multi-page websites using HTML.
- Creating responsive layouts using CSS Grid, Flexbox and media queries.
- Implementing interactive navigation using JavaScript.
- Building product cards and product detail layouts.
- Creating CSS-based image galleries.
- Designing a consistent brand identity and user interface.
